# Experiment 1 – Symbol Table

## Aim

To implement a Symbol Table using C and perform basic operations such as creation, insertion, modification, searching, and displaying of identifiers.

## Objective

The objective of this program is to demonstrate the basic operations performed on a symbol table in compiler design. The program stores variable names and their corresponding values and allows the user to perform different operations.

## Operations Performed

1. Create a symbol table
2. Insert a variable
3. Modify a variable
4. Search for a variable
5. Display the symbol table
6. Exit

## Software Used

- Dev-C++
- C Programming Language

- `symbol_table.c` – Source code
- `output.txt` – Sample execution output
