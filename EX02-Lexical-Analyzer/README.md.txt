# Experiment 2 - Lexical Analyzer

## Aim

To develop a lexical analyzer using the LEX tool to recognize tokens in a C program.

## Description

A lexical analyzer reads the input C program and identifies different types of tokens such as keywords, identifiers, constants, operators, and other symbols.

## Algorithm

1. Start the program.
2. Define the required patterns for the tokens.
3. Read the C source program as input.
4. Match the input characters with the defined patterns.
5. Identify and display the recognized tokens.
6. Continue scanning until the complete input is processed.
7. Stop the program.

The lexical analyzer program is implemented and executed using the required compiler/tool.
